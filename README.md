# Bus ETA Prediction

This project explores how to predict bus arrival/travel times using historical trip, stop, and route data. The workflow covers data cleaning, exploratory analysis, feature engineering, classical machine learning, deep learning, and model explainability.

## Goal

Estimate bus travel time or ETA more accurately by using temporal, route, and operational features derived from raw transit data.

## Typical workflow

1. Start with the EDA and data quality checks in `notebooks/01_eda.ipynb`.
2. Clean and visualize data in `notebooks/02_cleaning_and_visuals.ipynb`.
3. Build engineered features in `notebooks/03_feature_engineering.ipynb`.
4. Train baseline models in `notebooks/04_classical_ml.ipynb`.
5. Evaluate a deep learning approach in `notebooks/05_deep_learning.ipynb`.
6. Review advanced plots and SHAP explanations in `notebooks/06_advanced_visuals.ipynb` and `notebooks/07_shap_explainability.ipynb`.
